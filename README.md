## How this board works

This GitHub repository **is** the product. Listings are stored in [`data/jobs.json`](data/jobs.json) and the table above is generated automatically.

1. Public career feeds are collected on a schedule (GitHub Actions, about every 6 hours).
2. Roles are normalized, classified, and deduplicated.
3. The README is regenerated from current active jobs.
4. **Apply ↗** always points at the employer (or the legitimate source board they publish).

## Local setup

```bash
git clone https://github.com/nehaabalaji/Supply-Chain-Internships.git
cd Supply-Chain-Internships

python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate

pip install -r requirements.txt
pytest
python scripts/update_jobs.py --dry-run
python scripts/generate_readme.py
```

Requires **Python 3.11+**.
